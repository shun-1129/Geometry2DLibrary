### 2.1. クラス図

```plantuml
@startuml クラス図
class クラス名
{
    - フィールド: 型
    + プロパティ: 型
    # メソッド1(引数): 数値

}
@enduml
```

### 2.2. シーケンス図

```plantuml
@startuml シーケンス図
actor User as user
participant メソッド as method

user -> method
method --> user
@enduml
```
